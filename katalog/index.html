Neues Applet hinzufügen

Das Anlegen läuft über Claude Code, nicht über dieses Fenster. So gehst du vor:

1Öffne dein Projekt-Terminal mit Claude Code und schreib: neues applet
2Claude fragt dich nach Typ (Game, Fragebogen, Übung …) und einer kurzen Beschreibung — einfach in eigenen Worten antworten.
3Claude baut das Applet und fragt zwischendurch immer wieder: "Soll ich es pushen?" — du bestätigst, wenn du zufrieden bist.
4Nach dem Push erscheint das Applet automatisch in dieser Liste, als Entwurf (nicht veröffentlicht).
5Hier im Katalog Namen prüfen, veröffentlichen und den Embed-Code für Framer kopieren.
Hinweis: Dieses Fenster ist eine Anleitung, kein Formular — das eigentliche Bauen passiert bei dir in Claude Code.
